# The Long Roast: Lawmakers and the File They Cannot Convert

An entry for the [make.fun](https://make.fun/c/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7) bounty
**"The Long Roast: Lawmakers and the File They Cannot Convert"**.

## What it does

`main.ts` writes a single satirical sentence to `/output/entry.txt` — a roast
of the lawmakers who would regulate AI, crypto and the internet, but cannot
convert a file to PDF. The sentence is fixed and deterministic: the program
takes no input, makes no network calls and uses only the Node.js standard
library, so every run writes the exact same bytes.

## Run it

Requires Node.js 22.18 or later:

```sh
node main.ts
cat /output/entry.txt
```
